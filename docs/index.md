## New to the group?

- [ ] Get added to the lab GitHub organization (ask the wiki maintainer)
- [ ] Read the [group tasks](group-organization/group-tasks.md) page and pick up your assigned duty
- [ ] Meet your [mentor](group-organization/mentors.md)
- [ ] Find the [owner](group-organization/equipment-owners.md) of each instrument you need and get trained before using it
- [ ] Add yourself to the [meeting schedule](meeting-schedule.md) presentation rotation
